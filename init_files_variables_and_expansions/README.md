# Shell, initialization files, variables and expansions

Este proyecto contiene scripts de Bash para el aprendizaje del manejo de archivos de inicialización, variables, expansiones y alias en el shell de Linux.

## Descripción de los Scripts

* **0-alias**: Crea un alias llamado `ls` que ejecuta el comando `rm -f *`.

* **1-hello_you**: Imprime "hello " seguido del nombre del usuario actual de Linux.
